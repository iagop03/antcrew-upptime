# antcrew-upptime

[![Uptime CI](https://github.com/iagop03/antcrew-upptime/workflows/Uptime%%20CI/badge.svg)](https://github.com/iagop03/antcrew-upptime/actions/workflows/uptime.yml)

Status page for [antcrew](https://antcrew.org) services, powered by [Upptime](https://upptime.js.org). Checks run every 5 minutes from GitHub Actions and results are published to [status.antcrew.org](https://status.antcrew.org).

## Monitored services

| Service | URL |
|---------|-----|
| Platform INT | https://platform-int.antcrew.org/health |

## How it works

Upptime uses GitHub Actions as the uptime monitor, GitHub Issues to track incidents, and GitHub Pages to host the status page. No external server required.

- Uptime data is stored in the [](./history) folder
- Incidents are tracked as [GitHub Issues](https://github.com/iagop03/antcrew-upptime/issues)
- Status page: [status.antcrew.org](https://status.antcrew.org)
